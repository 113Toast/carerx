📖 高齡多重用藥檢核與衛教系統 — 使用說明

一、臨床操作 3 步驟

  1. ① 病人與用藥：填入年齡、性別、eGFR 與 CrCl（有共病時展開勾選），再搜尋藥名／健保碼或點「📷 拍照辨識處方箋」加入用藥。
  2. ② 安全檢核：系統即時檢核同學名重複用藥與 2023 AGS Beers Criteria（Tables 2～7），可依嚴重度篩選檢視，並一鍵產生給長輩的白話回診提醒。
  3. ③ 衛教單設定與匯出 PDF：依需求勾選顯示欄位與列印語言，在右側工具列調整字體大小（精簡／標準／放大／特大）後點「🖨️ 列印 / 匯出 PDF」。電腦版亦可左右拖曳中間分隔線調整工作區寬度。

二、關於 2023 AGS Beers Criteria 提醒

  • Beers Criteria 標示的是「潛在不適當用藥（PIM）」，並非絕對禁忌，應結合長輩治療目標與醫師共同討論，切勿讓病人自行突然停藥。
  • 本系統內建高齡白話衛教字典與生活飲食模板，免 API 即可使用；填入 Gemini API Key 後可啟用「處方箋拍照辨識」與「AI 一鍵白話改寫」。
