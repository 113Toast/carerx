# 健保藥品仿單資料庫 — 說明文件

給社區藥局藥師查詢用的健保給付藥品資料庫。藥師輸入藥名、健保代碼、許可證字號或成分，就可以查到這個藥的基本資料、外觀圖、仿單重點和仿單原文。

- 範圍：健保**目前給付中**的西藥品項（支付價大於 0）；中藥排在第二階段
- 資料日期：見資料庫 `meta` 表的 `built_at`（本版：民國 115 年 11 月 24 日建置）

```
 健保署 健保用藥品項                食藥署 許可證資料集 (InfoId 36)
 ┌──────────────┐  藥品代碼超連結   ┌──────────────────┐
 │ 健保代碼       │──licId (8碼)──▶│ 許可證字號          │
 │ 品名/成分/價格 │                 │ 適應症/劑型/類別    │
 └──────────────┘                 └────────┬─────────┘
                                            │ 許可證字號
                     ┌──────────────────────┼──────────────────────┐
                     ▼                      ▼                      ▼
           仿單資料集 (InfoId 39)     外觀資料集 (InfoId 42)    仿單查詢平台
           仿單連結                    外觀圖/形狀/顏色/刻痕      仿單全文
```

- 一個**健保代碼**只對到一張許可證；一張**許可證**可能對到好幾個健保代碼（例如不同包裝）
- 仿單、外觀圖、重點都掛在「許可證」底下，所以同一張許可證的不同健保代碼會顯示相同的仿單

## 資料表（SQLite）

### `drugs` — 健保品項（查詢入口，一個健保代碼一列）
| 欄位 | 說明 |
|---|---|
| nhi_code | 健保代碼（主鍵） |
| name_zh / name_en | 健保登錄的中英文品名 |
| ingredient | 成分與含量 |
| spec_qty / spec_unit | 規格量、規格單位 |
| single_compound | 單方／複方 |
| nhi_price | 健保支付價 |
| nhi_dosage_form | 劑型（健保） |
| drug_class | 藥品分類（研發廠、BA/BE 學名藥…） |
| atc_code | ATC 代碼 |
| nhi_group | 分類分組名稱 |
| vendor / manufacturer | 藥商／製造廠 |
| license_no | 許可證字號（連到 `licenses`） |

### `licenses` — 許可證（一張許可證一列）
| 欄位 | 說明 |
|---|---|
| license_no | 許可證字號（主鍵） |
| rx_class | 藥品類別（須由醫師處方使用、指示藥、成藥…） |
| controlled_level | 管制藥品分類級別 |
| dosage_form | 劑型（許可證） |
| indication | **適應症**（許可證登記內容） |
| usage_on_license | 用法用量（許可證登記內容，常寫「詳見仿單」） |
| label_source | 仿單來源：`結構化文字` / `PDF文字層` / `PDF-OCR` / `無` |
| label_confidence | 文字可信度：`高` / `中` / `低` / `無`（見下方說明） |
| label_url | 食藥署原始仿單連結 |
| shape / color / score_line / size_mm / imprint1 / imprint2 | 外觀：形狀、顏色、刻痕、尺寸 (mm)、藥上印字 |
| image_file | 外觀圖檔名（`images/許可證字號.jpg`） |
| image_url | 食藥署原始外觀圖連結（原尺寸） |

### `key_points` — 仿單重點（一個重點一列）
| 欄位 | 說明 |
|---|---|
| license_no | 許可證字號 |
| tag | 重點類別代碼（見下表） |
| tag_label | 顯示用標籤 |
| ord | 排序 |
| text | **仿單原句**（不是 AI 改寫） |
| source_section | 出自仿單哪一節，例如「4 禁忌」「7 交互作用」 |

| tag | 顯示 | 抓取來源 |
|---|---|---|
| contraindication | ⛔ 禁忌症 | 「禁忌」章節；成藥格式的「有下列情形者，請勿使用」 |
| warning | ⚠️ 重要警語 | 特殊警語／加框警語；警語章節中含「立即停用、禁止、嚴重、致命」等字的句子；成藥格式的「使用前請洽醫師」「出現以下症狀請停藥」 |
| timing | 🍽 服用時間 | 用法用量中提到飯前、飯後、空腹、睡前等的句子 |
| food | 🥛 飲食注意 | 交互作用、警語、用法中提到酒精、葡萄柚、牛奶、制酸劑、咖啡因、高鉀、維生素 K、酪胺等的句子 |
| drug_interaction | 💊 重要藥物交互作用 | 交互作用中「禁止併用、不建議併用、劑量勿超過」等句子 |
| population | 🤰 特殊族群 | 懷孕、哺乳、小兒、老年、肝腎功能不全的注意事項 |
| driving | 🚗 開車/操作機械 | 提到駕駛、操作機械、嗜睡的句子 |
| storage | 📦 儲存條件 | 儲存條件章節 |

### `label_sections` — 仿單全文（依章節）
| 欄位 | 說明 |
|---|---|
| license_no | 許可證字號 |
| ord | 章節順序 |
| section_id | 章節編號，例如 `4`、`5.1` |
| title | 章節名稱 |
| depth | 層級（1 = 大章節，2 = 小節…） |
| text | 章節內文；表格以 Markdown 表格保存 |

### `drug_search` — 全文搜尋索引（FTS5 trigram）
可以用部分字串搜尋健保代碼、許可證字號、中英文品名、成分、ATC 碼。全形數字已轉成半形，所以搜「850」也找得到「８５０毫克」。

```sql
-- 例：搜尋「庫魯化」
SELECT d.nhi_code, d.name_zh, d.license_no
FROM drug_search s JOIN drugs d ON d.nhi_code = s.nhi_code
WHERE drug_search MATCH '庫魯化' LIMIT 20;

-- 例：用健保代碼取出一個藥的完整資料
SELECT * FROM drugs d JOIN licenses l ON l.license_no = d.license_no WHERE d.nhi_code = 'BC182311G0';
SELECT tag_label, text, source_section FROM key_points WHERE license_no = '衛署藥輸字第018231號' ORDER BY tag, ord;
SELECT section_id, title, depth, text FROM label_sections WHERE license_no = '衛署藥輸字第018231號' ORDER BY ord;
```
注意：trigram 搜尋的關鍵字至少要 3 個字元；只有 1～2 個字的查詢，請改用 `LIKE '%關鍵字%'`。

## 文字可信度（label_confidence）

| 等級 | 來源 | 說明 |
|---|---|---|
| 高 | 結構化文字 | 食藥署電子結構化仿單，章節固定、文字正確 |
| 中 | PDF文字層 | 從 PDF 直接抽出的文字；內容正確，但雙欄排版可能讓句子順序錯亂，章節是用標題自動判斷的 |
| 低 | PDF-OCR | 掃描圖用 OCR（Tesseract）轉文字；**可能有錯字，藥名、劑量務必以原始仿單為準** |
| 無 | — | 食藥署沒有提供仿單，只能顯示許可證上的適應症 |

**建議網頁的呈現方式：** 可信度為「中」或「低」時，在重點區塊上方顯示「自動擷取，請點原始仿單確認」，並附上 `label_url` 連結。

## 重要提醒

1. **重點是「規則式擷取的原句」，不是 AI 摘要。** 好處是不會無中生有；缺點是可能漏抓、或抓到不太相關的句子。畫面上一定要能展開仿單原文。
2. 這個資料庫是查詢輔助工具，**不能取代藥師的專業判斷和原始仿單**。
3. 資料來源是政府開放資料（政府資料開放授權條款第 1 版），使用時請註明出處：
   「資料來源：衛生福利部中央健康保險署、衛生福利部食品藥物管理署」。
4. 仿單會更新：健保檔每月更新，食藥署資料每週更新。建議至少每月重建一次（用 `scripts.zip` 裡的程式）。
5. 食藥署要求藥商在 115 年底前全面改用電子結構化仿單，之後重建時，「PDF-OCR」的比例應該會明顯下降。
